## The one-line bridge

INTERFACE is about how humans interface with machines. Bright Data is about how
machines interface with the web. Every track closes the loop: human in, interface,
agent, live web out.

## The event

- Official a16z Tech Week event, grant-funded, on the Tech Week calendar Sept 8
- Sat–Sun Oct 10–11, 2026 · ~120 hackers + ~20 mentors/judges/volunteers
- 80%+ current students or grads within 2–3 years, technical fields (a grant condition)
- Five tracks: NEURAL, VOICE, TOUCH, VISION, OPEN · 20–30 working demos
- The only 24-hour-format hackathon on their Tech Week slate — their other events are
  half-day, so this is the flagship-scale one without them having to run it

## The format, adjusted for the Loft

No overnight. Nobody sleeps in the building.

- **Saturday:** doors 9am (setup from 8am), building closes 11pm
- **Sunday:** doors 9am, demo expo 11:30am, top-10 finals 1:30pm, close 3:30pm,
  cleanup done by ~6pm
- Hackers keep building from home overnight, so the 24-hour build clock survives

Venue needs: room for ~140, build tables + power, Wi-Fi for 100+ devices, AV for the
opening talk and finals.

## What Bright Data gets as presenting sponsor

Framed as a trade — the venue for the presenting slot. No tier sheet, no cash ask.

1. **Naming:** "INTERFACE at The Web Data Loft, presented by Bright Data" on Partiful,
   the site, and all event comms
2. **The opening talk, Saturday morning** — 120 builders, and the slot fits their
   existing DevRel material (Rafael Levi's "Your Agent's Biggest Lie: 'I Searched the
   Web'" is practically written for this room)
3. **One of the three onboarding workshops:** a hands-on Web MCP session in hour one,
   so every team starts with live web access wired in
4. **Starter kit placement:** The Web MCP free tier + Bright Data credit codes for
   every hacker (their Scrape-Verse precedent: $50 codes)
5. **The Bright Data Challenge:** best use of live web data, open to every track,
   judged on production-readiness; winners referred into their AI Startup Program
   (up to $20K credits — their program, their pipeline)
6. **Opt-in resume book** of a room that is 80%+ students and new grads in technical
   fields — their early-talent funnel, pre-filtered
7. **Post-event write-up** featuring track winners and what they built on Bright Data
   infrastructure, in their space

## Track-by-track: how each track supports Bright Data

- **NEURAL** — brain signals as agent triggers. EEG intent classification fires Web
  MCP actions: think it, and an agent fetches it. The most demo-able version of
  "agents in production" that exists.
- **VOICE** — voice agents that act on the live web instead of canned APIs. A voice
  loop plus Web MCP retrieval is the on-stage fix for the agent that lies about
  having searched the web.
- **TOUCH** — feel the live web. Haptic rendering of real-time data streams pulled
  through Web MCP, and teleoperation demos grounded in live data — the physical-AI
  story at human scale.
- **VISION** — camera in, context out. Point a lens at the world and an agent
  enriches it with live web data. Sits directly on their VLA thesis that multimodal
  models need web-scale, physics-grounded data.
- **OPEN** — the Bright Data Challenge lives here and reaches across all tracks:
  any project, any interface, judged on whether the agent behind it would survive
  production.
